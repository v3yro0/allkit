# allkit · v1.0.0 beta

**one app. 30 tools. endless possibilities.**

allkit is a modern, midnight-themed everyday toolkit that brings useful utilities, creative features, and entertainment together in one polished application.

## ✨ features

### 🛠️ everyday tools
- standard and scientific calculators
- unit and currency converters
- stopwatch, countdown timer, and alarm
- world clock and timezone converter
- QR code generator and scanner
- barcode scanner
- password generator
- compass and digital ruler

### 🎨 creative utilities
- color picker and palette generator
- word counter and text case converter
- random number generator
- age and date calculators
- percentage, discount, and tip calculators

### 🎮 fun and entertainment
- magic 8 ball
- wheel spinner
- reaction time tester
- virtual pet
- configurable dice roller

### 👀 hidden discoveries
10 discoverable easter eggs are scattered throughout allkit, including secret interactions, a hidden terminal, retro themes, and unexpected surprises.

## 📱 platform support

| Platform | Availability |
|---|---|
| Windows | Portable x64 beta |
| Android | Debug-signed beta APK |
| iOS | Xcode project supplied; requires macOS and signing |

## 🔒 privacy

- no accounts
- no advertisements
- no analytics
- personal settings stored locally
- passwords and typed tool text are not saved
- camera frames and selected photos are processed locally

## ⚙️ technology

Built using React, Capacitor, and Electron, with a shared interface across platforms.
